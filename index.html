RMC Grade Management System

Context

Regis Marie College needed a system to manage student records, post term grades, and calculate GWA. The project was built as an academic group collaboration to solve a real institutional workflow problem.

Challenge

Designing a desktop application with proper role-based access (admin vs. student views), grade computation logic (GWA calculation), and SQL Server database integration. Had to ensure data integrity and input validation for academic records.

My Role

Contributed to database schema design, grade management features, and student records management. Worked on the VB.NET Windows Forms UI and SQL Server integration using ADO.NET.

Result
  • Completed a functional desktop grade management system
  • Implemented role-based login for admins and students
  • Built GWA calculation and grade posting features
  • Integrated SQL Server Express for persistent data storage
Tech Stack
VB.NET Windows Forms SQL Server ADO.NET
